# Simulador-Hospitalar-Multiagente
O objetivo deste programa é desenvolver uma aplicação visual no ambiente Processing (modo Java) que simule a dinâmica de um setor de atendimento hospitalar. A simulação baseia-se em um modelo multiagente, onde cada paciente é representado como um agente autônomo com objetivos, estados e tomadas de decisão próprias.


O sistema de integração do Processing ao Java foi colaborado por [Eduardo Lamonier](https://github.com/eduardo-lamounier) e [Heitor Freitas](https://github.com/Zerocentos).
